# Contributing

Thanks for improving AI Cloud Memory.

1. Open an issue for a significant behavioural or data-model change.
2. Fork the repository and create a focused branch.
3. Add or update tests for the requested behaviour.
4. Run `npm run check` and `npm audit --audit-level=high`.
5. Open a pull request with the problem, approach, verification and migration impact.

Keep changes owner-scoped, preserve D1 as canonical and do not introduce a required hosted service. Never commit credentials, private memory data, real account identifiers or adopter URLs.

Codex Cloud review, if enabled by maintainers, is external repository administration and is not a product dependency or Community Edition feature.
