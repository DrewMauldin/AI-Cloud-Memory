# Support

Use GitHub Discussions for setup questions and GitHub Issues for reproducible defects.

Before posting:

- remove secrets, tokens, cookies and private memory content
- include the release version and Cloudflare deployment region only if useful
- state whether semantic search is enabled
- include the failing command, sanitised error and expected outcome
- confirm whether dashboard login and `cloudmemory_health` work

Community support is best effort. Cloudflare account, billing, quota and GitHub OAuth issues may require the respective provider’s support.
